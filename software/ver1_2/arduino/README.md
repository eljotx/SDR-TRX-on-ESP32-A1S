You can find more information about FFT at the following link:

[fft description in Arduino Audio Tools](https://github.com/pschatzmann/arduino-audio-tools/wiki/FFT) 

This software version includes an FFT module named AudioEspressifFFT—part of esp-dsp—which does not require a separate installation (unlike AudioRealFFT). However, using other FFT versions—such as ESP32-FFT, KissFFT, or fixedpoint-fft—requires the additional installation of libraries found at the link above.
